# عقار مصر — دفتر محلي

تطبيق عربي لتسجيل عروضك يدويًا، والبحث والفلترة حسب البيع أو الإيجار، وترتيب السعر، والمفضلة وحساب السعر لكل متر. يبدأ فارغًا؛ لا يقدّم إعلانات أو أسعار سوق. الحفظ على المتصفح المستخدم فقط، مع توضيح فشل القراءة أو الحفظ. لا حسابات أو خادم بيانات أو تبعيات JavaScript خارجية.

شغّل من مجلد المشروع:

```sh
python -m http.server 8080 --bind 127.0.0.1
npm test
```

افتح http://127.0.0.1:8080. Node22 استُخدم للاختبارات؛ Python للتقديم المحلي فقط. لا تعتمد على file:// لأن استيراد ES modules وتخزين المتصفح يختلفان. البيانات ليست مشفرة أو متزامنة. لا تدخل بيانات حساسة في جهاز مشترك.

زر «تنزيل الدفتر الحالي» يصدر ملف JSON صالحًا للنقل. اختر ملفًا لمعاينة عدد العروض وأول خمسة عناوين؛ يفحص التطبيق كل الحقول، ثم يحتفظ بنسخة الدفتر السابق في ذاكرة الصفحة ويتيح تنزيلها قبل موافقة الاستبدال. لا يحدث الاستبدال بمجرد اختيار الملف. إغلاق الصفحة يفقد نسخة الذاكرة؛ احتفظ بالتنزيل على جهازك. يتطلب الملف `schema_version: 1` وقائمة `properties`، بحد 200 عرض و512 كيلوبايت، ومعرّفات فريدة وحقول رقمية فعلية. الصيغ الأخرى والملفات غير الصالحة ترفض بالكامل.

عند فشل الحفظ أثناء الاستيراد يبقى الدفتر السابق ظاهرًا ومحفوظًا. إن كانت البيانات المحفوظة غير مقروءة أصلًا، يتاح تنزيلها كما هي، ويستبدل الاستيراد دفتر الجلسة فقط دون الكتابة عليها؛ نزّل الدفتر الجديد قبل إغلاق الصفحة. إذا تغير التخزين من نافذة أخرى أثناء المعاينة، يرفض الاستبدال ويطلب إعادة التحميل. أي تعديل في الدفتر يلغي المعاينة القديمة.

اختر «قارن هذا العرض» في حتى ثلاث بطاقات من النوع نفسه. يظهر جدول السعر والمساحة وسعر المتر؛ الإيجار محدد لكل شهر. لا تجمع عروض البيع والإيجار في مقارنة واحدة. الحذف يزيل العرض من المقارنة، والاستيراد يبدأ اختيارًا جديدًا.

التحقق: **12 اختبار Node ناجحًا** و**11 مجموعة Edge حقيقية ناجحة** عبر HTTP على مصدر `27510ad1`، تشمل التنزيل والاستعادة والتخزين التالف والنافذة الأخرى والمقارنة على الهاتف. [النتيجة المسجلة](evidence/browser-portability.json) و[المراجعة والأدلة](DEVELOPMENT_REVIEW_AR.md).

يمكن تكرار فحص المتصفح من جذر المستودع باستخدام Edge ونسخة Playwright مثبتة مسبقًا؛ أداة التحقق لا تنزل تبعيات. شغّل الخادم المحلي السابق في نافذة، ثم في نافذة PowerShell أخرى:

```powershell
$env:PLAYWRIGHT_MODULE = 'C:\path\to\existing\node_modules\playwright'
$env:URL = 'http://127.0.0.1:8080/'
$env:OUTPUT_DIR = 'D:\path\to\aqar-test-evidence'
# اختياري: SHA المصدر الذي تحقق منه المشغل؛ لا يستنتجه المتصفح.
$env:SOURCE_SHA = git rev-parse HEAD
node scripts/verify-portability.cjs
```

السكربت يقبل URL على localhost أو عنوان loopback فقط، ويستخدم سياقات متصفح جديدة وبيانات اصطناعية. يحفظ JSON التنزيل والنتيجة في `OUTPUT_DIR`؛ إن لم يحدد، ينشئ مجلدًا مؤقتًا جديدًا ويطبع مساره. الصور اختيارية عبر `SCREENSHOT=1`. `--smoke` يكتفي بمسار النموذج والمفضلة وتنزيل JSON، و`--help` يشرح الخيارات. لا تحتاج هذه الأداة إلى ملف cookies أو جلسة مستخدم.
