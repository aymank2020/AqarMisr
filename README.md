# عقار مصر — دفتر محلي

تطبيق عربي لتسجيل عروضك يدويًا، والبحث والفلترة حسب البيع أو الإيجار، وترتيب السعر، والمفضلة وحساب السعر لكل متر. يبدأ فارغًا؛ لا يقدّم إعلانات أو أسعار سوق. الحفظ على المتصفح المستخدم فقط، مع توضيح فشل القراءة أو الحفظ. لا حسابات أو خادم بيانات أو تبعيات JavaScript خارجية.

شغّل من مجلد المشروع:

```sh
python -m http.server 8080 --bind 127.0.0.1
npm test
```

افتح http://127.0.0.1:8080. Node22 استُخدم للاختبارات؛ Python للتقديم المحلي فقط. لا تعتمد على file:// لأن استيراد ES modules وتخزين المتصفح يختلفان. البيانات ليست مشفرة أو متزامنة؛ حفظ نسخة احتياطية/export ومقارنة عروض مختارة مراحل لاحقة. لا تدخل بيانات حساسة في جهاز مشترك.
